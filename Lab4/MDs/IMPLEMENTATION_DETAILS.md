# Подробное описание реализации

Ниже — пошаговое объяснение того, как устроены библиотеки и программы, с вырезками из кода. Все комментарии в исходниках тоже на русском и поясняют каждую строчку.

## Контракты (`contracts.h`)
Две функции, которые должны быть во всех реализациях:
```c
float SinIntegral(float A, float B, float e);   // интеграл sin(x) на [A,B] с шагом e
int *Sort(const int *array, size_t length);     // сортировка массива, возвращает новый malloc-буфер
```
Почему нужны: программы знают только эти сигнатуры, чтобы можно было статически линковаться или искать символы через `dlsym`.

## Библиотека 1 (`libimpl1.c`)
Реализация интеграла методом прямоугольников и сортировки пузырьком.
Ключевые моменты:
- Проверка шага `e` на `<= 0`, в этом случае возвращаем `0.0f`.
- Если границы переданы в обратном порядке, меняем их местами и запоминаем знак (`sign = -1`), чтобы инвертировать результат.
- Суммируем площади прямоугольников высотой `sinf(x)` и шириной `step` (последний прямоугольник может быть уже).
- Сортировка: копируем входной массив в новый буфер (`malloc + memcpy`), затем два вложенных цикла пузырьковой сортировки.

Фрагмент:
```c
// Проверяем, что шаг положительный; если нет — возвращаем 0 как сигнал ошибки ввода
if (e <= 0.0f) {
    return 0.0f;
}
// Если пользователь ввёл A > B, меняем местами и запоминаем знак
if (start > end) {
    float tmp = start;
    start = end;
    end = tmp;
    sign = -1;
}
// Два вложенных цикла пузырьковой сортировки
for (size_t i = 0; i < length; ++i) {
    for (size_t j = 0; j + 1 < length - i; ++j) {
        if (copy[j] > copy[j + 1]) {
            int tmp = copy[j];
            copy[j] = copy[j + 1];
            copy[j + 1] = tmp;
        }
    }
}
```

## Библиотека 2 (`libimpl2.c`)
Реализация интеграла методом трапеций и сортировки Хоара (быстрая сортировка).
Ключевые моменты:
- Та же проверка шага и перестановка границ с запоминанием знака.
- Для каждого шага берём левую и правую точки `x` и `next`, площадь трапеции `0.5 * (sinf(x) + sinf(next)) * width`.
- Быстрая сортировка: опорный элемент из середины, два указателя `i` и `j` сходятся к центру, потом рекурсивные вызовы для подотрезков.
- Также копируем вход в новый буфер, чтобы не портить исходные данные.

Фрагмент:
```c
float next = x + e;
if (next > end) {
    next = end; // подрезаем последний шаг
}
float width = next - x;
acc += 0.5f * (sinf(x) + sinf(next)) * width; // площадь трапеции
```
```c
// Опорный элемент выбираем из середины
int pivot = array[(left + right) / 2];
// Разделяющая часть: продвигаем i и j навстречу
while (i <= j) {
    while (array[i] < pivot) ++i;
    while (array[j] > pivot) --j;
    if (i <= j) {
        int tmp = array[i];
        array[i] = array[j];
        array[j] = tmp;
        ++i;
        --j;
    }
}
```

## Статически линкованная программа (`main_static.c`)
Использует первую библиотеку, подключённую на этапе линковки. Читает команды пользователя.
Команды:
- `1 A B e` — вызвать `SinIntegral` (метод прямоугольников).
- `2 n1 n2 ...` — вызвать `Sort` (пузырьковая).
- `q`/`exit` — выход.

Разбор чисел: функция `parse_ints` режет строку на токены, конвертирует `strtol`, складывает в динамический массив (расширяет `realloc` при необходимости). Сортировка возвращает новый буфер — его и буфер парсера нужно освободить `free`.

Фрагмент:
```c
// Цикл чтения пользовательских команд до EOF или команды выхода
while (printf("> "), fflush(stdout), fgets(line, sizeof(line), stdin)) {
    char *command = strtok(line, " \t\r\n");
    ...
    float result = SinIntegral(A, B, e); // вызываем из статически линкованной либы
    ...
    int *sorted = Sort(values, length); // вызываем сортировку из библиотеки
}
```

## Динамически загружаемая программа (`main_dynamic.c`)
Загружает обе `.so` через `dlopen`, ищет символы `SinIntegral` и `Sort` через `dlsym`, умеет переключать активную библиотеку по команде `0`.
Команды:
- `0` — переключить текущую реализацию (`libimpl1.so` ↔ `libimpl2.so`).
- `1 A B e` — интеграл sin(x) через активную реализацию (`rectangles` или `trapezoids`).
- `2 n1 n2 ...` — сортировка через активную реализацию (`bubble` или `quicksort`).
- `q`/`exit` — выход.

Важно: при ошибке загрузки или разрешения символов программа пишет в `stderr` и завершает работу. При выходе все библиотеки выгружаются через `dlclose`.

Фрагмент:
```c
lib->handle = dlopen(lib->path, RTLD_LAZY); // открываем библиотеку
lib->sin_integral = (sin_func_t)dlsym(lib->handle, "SinIntegral"); // ищем символ
lib->sort = (sort_func_t)dlsym(lib->handle, "Sort");               // ищем символ
```
```c
if (strcmp(command, "0") == 0) {         // переключение активной библиотеки
    current = (current + 1) % lib_count; // двигаем индекс по кругу
    printf("Switched to: %s\n", libs[current].name);
    continue;
}
```

## Сборка и запуск
Сборка всех частей:
```sh
make
```
Запуск статической версии:
```sh
./main_static
```
Запуск динамической версии с переключением библиотек:
```sh
./main_dynamic
```

## Основные идеи
- Контракт в одном заголовке, чтобы реализации и программы были согласованы.
- Каждая библиотека реализует обе функции: интеграл и сортировку.
- В статике выбирается фиксированная реализация на этапе линковки.
- В динамике обе реализации загружаются и можно переключать их в рантайме.
- Все выделения памяти явно освобождаются, чтобы избежать утечек.
