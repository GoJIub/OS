# Тестовые данные

## main_static
Пример с интегралом (метод прямоугольников):
```
1 0 3.14159 0.001
```
Ожидаемое значение интеграла sin(x) на [0, π] ≈ 2.000 (для шага 0.001 будет близко к 1.999–2.001).

Пример с сортировкой (пузырёк):
```
2 5 1 -3 10 0 7
```
Ожидаемый вывод:
```
-3 0 1 5 7 10
```

## main_dynamic
Стартует с библиотекой `libimpl1.so` (прямоугольники + пузырёк).

Переключение реализации:
```
0
```
После этого активна `libimpl2.so` (трапеции + быстрая сортировка).

Интеграл (трапеции):
```
1 0 3.14159 0.001
```
Ожидаемое значение ≈ 2.000 (погрешность ещё меньше, чем в прямоугольниках).

Сортировка (quicksort):
```
2 8 4 2 9 -1 0
```
Ожидаемый вывод:
```
-1 0 2 4 8 9
```

Завершение работы:
```
exit
```
